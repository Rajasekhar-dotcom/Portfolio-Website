# Portfolio Website

A modern, responsive personal portfolio showcasing my skills, projects, and journey as a Computer Science undergraduate. Designed with a clean interface, a dark green color palette, and smooth animations to deliver an engaging user experience.

## ✨ Features

- **Responsive Design** – Adapts seamlessly to different screen sizes.
- **Interactive Hero Section** – Introduces me and my work.
- **Skills Showcase** – Displays technical skills through an animated, horizontally scrolling technology bar.
- **Projects Section** – Highlights my development projects and work.
- **Experience Section** – Showcases my experience and achievements.
- **Smooth Animations** – Includes scroll-based reveal effects and subtle transitions.
- **Contact Section** – Provides ways to connect with me.

## 🛠️ Tech Stack

- **HTML5** – Website structure
- **CSS3** – Styling, responsive layouts, and animations
- **JavaScript** – Interactivity and dynamic behavior

## 📂 Project Structure

```text
Portfolio-Website/

```

## 🚀 Getting Started

Run the portfolio locally in a few simple steps.

1. Clone the repository:

   ```bash
   git clone https://github.com/Rajasekhar-dotcom/Portfolio-Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio-Website
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code for local development.

No additional dependencies or build tools are required.

## 🎨 Design Philosophy

The portfolio focuses on simplicity, readability, and subtle interactions. A dark green and light green color palette, rounded elements, and smooth animations create a consistent visual identity while keeping the content easy to explore.
